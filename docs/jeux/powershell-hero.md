# PowerShell Hero

*Jeu existant sur universe.awoui.com — fiche reconstituée depuis la description du propriétaire (2026-08-06). À enrichir.*

## Pitch

**Guitar Hero, mais avec des commandes PowerShell.** Les commandes défilent en
rythme et le joueur doit les « jouer » au bon moment.

## Formule

- **Mécanique d'arcade** : jeu de rythme type Guitar Hero (notes qui descendent
  sur des pistes, timing, combos).
- **Concept IT** : les commandes PowerShell — le joueur mémorise cmdlets et
  syntaxe par répétition rythmée (mémoire musculaire).
