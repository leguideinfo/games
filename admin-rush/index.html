Windows Server · Salle d'arcade Awoui
Les tickets pleuvent sur ton infra Windows Server.

1. Sélectionne un ticket (le premier l'est déjà).
2. Tape la chaîne de services qui le résout, dans le bon ordre — ex : joindre un PC au domaine = DNS puis AD DS.
3. Chaque module de formation débloque de nouveaux services : pre-setup → DC/AD/DNS → PKI → IIS/HTTPS/VPN.

Bon service = progression. Erreur = temps perdu, série brisée. Ticket expiré = SLA rompu (3 = fin) — mais la solution s'affiche : on apprend aussi en échouant.
